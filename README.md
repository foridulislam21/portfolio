# Forid Portfolio

Modern developer portfolio built with Next.js, TypeScript, Tailwind CSS, Framer Motion and Lucide.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Customize

- `data/projects.ts` — projects
- `data/skills.ts` — skills
- `data/experience.ts` — experience
- `components/Hero.tsx` — name, social links and hero copy
- `components/Contact.tsx` — email address
- `app/layout.tsx` — SEO metadata

Replace the placeholder GitHub, LinkedIn and email values before publishing.
